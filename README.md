# Software FJ – Sistema Integral de Gestión

## Descripción del proyecto

Software FJ es un sistema desarrollado en Python para la gestión de clientes, servicios y reservas. El proyecto fue realizado como parte de la Fase 4 del curso de Programación de la UNAD.

## Funcionalidades principales

- Registro y consulta de clientes.
- Validación de datos personales.
- Gestión de servicios especializados.
- Creación, confirmación, cancelación y procesamiento de reservas.
- Cálculo de costos según el tipo de servicio.
- Control de disponibilidad de equipos.
- Manejo de excepciones personalizadas.
- Registro de eventos y errores mediante archivos de log.

## Tecnologías utilizadas

- Python.
- Programación orientada a objetos.
- Herencia, abstracción y polimorfismo.
- Manejo de excepciones.
- Módulo `logging`.
- Git y GitHub.

## Ejecución del sistema

1. Clonar o descargar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Ejecutar desde la terminal:

```bash
python main.py
```
